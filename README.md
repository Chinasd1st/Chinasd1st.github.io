# 小奶奶博客

小奶奶博客（Silentnrtx Blog）的源码仓库。

站点地址：**[https://silentnrtx.top/](https://silentnrtx.top/)**

记录音乐、动画、技术与日常。

## 技术栈

- [VuePress 2](https://v2.vuepress.vuejs.org/)
- [vuepress-theme-hope](https://theme-hope.vuejs.press/)
- pnpm
- 自建 Meting 播放器（`src/.vuepress/components/MetingPlayer.vue`）

## 本地开发

```bash
pnpm install
pnpm docs:dev    # http://localhost:1145
pnpm docs:build
```
